# Лабораторная работа БД

Учебный проект для управления базы данных для магазина игровых консолей в текстовой консоли

## Описание 

Программа позволяет управлять товарами (игровыми консолями) через текстовое меню и сохраняет данные в текстовый файл consoles.txt, файл можно редактировать вне программы и при запуске он автоматически загрузит изменения.

## Функциоал

1. Вывести все консоли
2. Добавить консоль
3. Редактировать консоль
4. Удалить консоль
5. Поиск по производителю
6. Поиск по цене
7. Сохранить в файл
0. Выход

## Запуск
```
1. Скачать все файлы
2. cd */lab_data
3. make
4. ./lab5
```
## Архитектура

